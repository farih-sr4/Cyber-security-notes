# Linux Part - 1

*Linux is used in cybersecurity and the terminal is used by you most of the time.*

Linux commands: 

  - whoami -> tells you who you are and what you can and cannot do.
  
  - echo -> to print something.

You can navigate around in Linux system without using your mouse, and it is an important skill to know.

To navigate around system's files via terminal, we use mostly these 4 commands that do almost all navigation.

  - ls -> lists the files and folders in working directory
  
  - cd -> change directory
  
  - cat -> show the contents of a file.
  
  - pwd -> print working directory

We can use a set of Linux commands to help us efficiently search for and through files.

  - find -> search for files by their name (find -name file.txt).
  
  - grep -> searches for specific text inside a file (grep "name" file.txt).

In Linux there are set of special characters that can combine commands together, these are called "Operators".

  - & -> Runs the command in background and returns the terminal ready for the next command.
  
  - && -> Runs both commands, but waits for the first command to execute and then executes the second one.
  
  - ">" -> Used to redirect the output of a command to a file, it overwrites the file's old content with this output.
  
  - ">>" -> Used to redirect the output of a command to a file, but doesn't overwrite the file's content instead appends the output to the content in a new line.
